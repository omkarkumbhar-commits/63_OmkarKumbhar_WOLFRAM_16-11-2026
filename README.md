# 63_OmkarKumbhar_WOLFRAM_16-11-2026
### Probability and statistical simulations performed using interactive Wolfram demonstrations.

---

### 1) Bivariate Normal Correlation

Observing how changing the population correlation ($\rho$) alters the scatter plot spread and sample correlation ($r$) for bivariate normal data.

---

### 2) Critical Regions in Hypothesis Testing

Examining how sample size and significance level ($\alpha$) shift the shaded rejection regions in right-tailed, left-tailed, and two-tailed tests.

---

### 3) Probability Density vs. Likelihood Function

Comparing the probability density curve $f(x;\mu)$ for a fixed mean against the likelihood curve $L(\mu \mid x_0)$ given an observed sample.

---

### 4) Bayes' Theorem and Conditional Probability

Calculating posterior probabilities $P(A \mid X)$ and $P(B \mid Y)$ from prior and conditional probabilities in a two-state model.
